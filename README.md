## 📖 Overview

This repository is a comprehensive starter kit designed for hands-on learning of **CI/CD and DevSecOps practice**.  
By leveraging Docker Compose, you can instantly spin up a full automated pipeline environment on your local machine to experiment with source code management, automated building, vulnerability scanning (SCA/DAST), artifact management, and automated deployment.

### 🚀 Tech Stack

- **Jenkins**: CI/CD pipeline orchestration and job automation.
- **GitLab**: Source code management (SCM) and code review workflows.
- **Dependency-Track**: Software Bill of Materials (SBOM) management and vulnerability analysis (SCA).
- **JFrog Artifactory**: Artifact repository for storing and managing built packages.
- **Ansible**: Infrastructure automation for automated application deployment.
- **OWASP ZAP**: Dynamic Application Security Testing (DAST).
